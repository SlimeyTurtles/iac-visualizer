What to try

Untrained, the greedy readout is distance-limited: near-perfect up to 3 hops, dead by 5 — the goal's activation gradient simply doesn't reach.

Every modulo task shares the same few goals (x, 0, 0), so unconstrained Hebbian potentiation (homeostasis 0, high cap) imprints a self-exciting attractor along that axis and success collapses. Homeostatic synaptic scaling (each node's total incident weight is conserved, so strengthening one route depresses the others) plus a tight cap keeps learning from destroying the gradient.

Compare a run with η = 0 against the same seed with learning on, and watch the rolling curve — weight potentiation in state space follows co-activation, not task success, which is exactly why it struggles to encode a relational rule like modulo.

Sibling pools change that picture: each node's out-neighbors (rival next-steps) mutually inhibit, collapsing the diffuse activation cloud into a sparse ridge (~25 active nodes instead of ~160). Co-activation then traces the winning route, so Hebbian learning becomes path-selective — in 600-episode runs it's the only regime where learning nudges success above the frozen-weights reference instead of below it.
