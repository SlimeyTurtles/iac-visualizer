IAC Pathfinding New

Randomly connected scenario ↔ action graph. Clamp two nodes and test whether plain IAC dynamics intrinsically find a path between them through spreading activation.

IAC Pathfinding + Positional Encoding New

Geometry-first variant: nodes get position vectors, connections follow nearest-neighbor similarity, and goal-directed inhibition lets competition itself route a plan between two clamped scenarios.

ART Pathfinding (Recall-Based) New

ESCF-style planning: an ART layer learns state hubs (vigilance = abstraction dial), hubs link to successor hubs, and best-first recursive recall — scored by cosine to the goal — searches until the goal hub resonates.

MLP Pathfinding (Layered States) New

MLP-shaped state graph: one current-state node at the bottom, random affordance-weighted actions between layers. Clamp the root and a goal, and measure whether IAC activation carves the easiest path. Supports lesioning.

MLP Pathfinding (Bulk Metrics) New

Sweep the layered planner over seed ranges: success / unreachable / dead-end rates, efficiency distribution vs the easiest possible path, filterable per-seed table with click-through to the interactive page.

Arithmetic Pathfinding (Hebbian Lattice) New

Every (A, B, C) triple is a state; edges are the arithmetic moves X ±= Y and X = 0. IAC spreads from clamped current + goal states while slow Hebbian potentiation (with homeostatic synaptic scaling) reshapes the lattice as it practices modulo tasks (A,B,C) → ((A+B) mod C, 0, 0).
ART Arithmetic

ART Addition (Localist) New

Two localist digit pools (0–9, one-hot) feed an ART hub layer whose outputs point at sum nodes 0–20. Train on every pair except those containing an excluded digit (default 4) and test whether recall can extrapolate addition it was never taught.

ART Addition (Distributed) New

Same adder, but each digit activates a Gaussian bump over its pool, so 4 overlaps 3 and 5. Nearby hubs vote for nearby sums — test whether overlap geometry is enough to extrapolate the held-out digit, and how σ and softmax gain shape the answer.

ART Arithmetic (Add & Subtract) New

Adds a third localist pool: a two-node operator (+ / −). Hubs recruit over the full (A, op, B) triple and wire to result nodes −9…18. Trained on all 100 pairs × both operators, with per-operator result grids.

ART Modulo (Recurrent Subtraction) New

The operator pool grows a done node and hubs learn state transitions: (Sub, A, B) → the next subtraction step, until the remainder flags done. Recall feeds back into the input so the network runs the algorithm — trained on mod 1, 2, 4, 5, with mod 3 never taught.

Action Graph (Step-Indexed Hebbian) New

Every triple (A, B, C) is a node branching through the same arithmetic actions (X += Y, X −= Y, X ×D, X ÷D, X = 0 on any variable). IAC spreads from the clamped current and goal states with decay only, and Hebbian credit lands on the action at step k rather than the state pair — a value-agnostic action sequence that hardens on the (A + B) mod C curriculum.

Hierarchy Emergence ART New

Flat ART with noisy samples + random sensory dropout. A general "fish" hub and species-level hubs emerge without forcing any hierarchy.

Hierarchy Emergence (Synthetic 12, Clean) New

Generated dataset of 8 species + 4 generic superordinates (tree, flower, bird, fish), no dropout. The cleanest demonstration that flat ART can recover all 12 prototypes.

Hierarchy Emergence (Synthetic 12, Dropout)

Same dataset but with random sensory dropout — pools randomly zeroed out per sample. Demonstrates the model's robustness to missing modalities.

Hierarchy Emergence (Corrupted + Decay) New

14 prototypes with 2 deliberately corrupted samples per concept mixed in. Templates decay every training step — orphan hubs recruited by garbage samples wither away while the 14 real hubs stay refreshed.
Unsupervised — Hierarchical

Forced Hierarchical ART New

Three parallel ART layers at increasing vigilance — coarse super-categories, mid-level categories, and fine-grained specific concepts. Hierarchy imposed by design.

ESCF New

The Emergent Semantic Cognition Framework — one hub-and-spoke mechanism run in three modes: perceptual categories from covariation at varying engagement, consequence-driven splitting/assembly, and goal-lens categorization (g ⊙ x).
