What this tests

The operator pool has only two units, and per-pool normalization makes it loud: flipping + to − drops that pool's similarity from 1 to 0, so 7 + 3 and 7 − 3 sit far apart (similarity 0.667) even though A and B match exactly. One small pool can carry as much distinctive weight as a whole digit.

Trained on everything, exemplar hubs make recall a lookup table — both operator grids should be fully green. The interesting probes are counterfactuals: set an exclude digit and the localist flat-tie failure from the addition page comes back, now once per operator.
